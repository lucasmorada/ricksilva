# ricksilva

A modern photography portfolio website created to showcase a photographer's work through a clean and visually focused interface.

## About

This project was developed as a personal website for a photographer, with a focus on presenting photography work in an elegant and responsive layout.

The interface was designed to keep the photographs as the main visual element while providing a simple and intuitive browsing experience.

## Features

* Responsive layout
* Photography portfolio showcase
* Clean and minimalist interface
* Mobile-friendly navigation
* Modern visual design
* Optimized project structure with reusable components

## Technologies

* React
* TypeScript
* Tailwind CSS
* Vite
* ESLint

## Getting Started

Clone the repository:

```bash
git clone https://github.com/lucasmorada/ricksilva.git
cd ricksilva
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local address provided by Vite.

## Purpose

The project was created to practice modern front-end development while building a real-world portfolio website for a photographer.

The main focus was on responsive design, component-based development, visual presentation, and creating a simple user experience centered around photography.
